<p>In order to test the possibility to create a platform for sharing the layers and the spatial dataset produced during our research activity we set up a geographic forest information system available at</p>



<p><a href="http://forestinfo.it/index.php/view/map/?repository=1&amp;project=forest_sharing" target="_blank" rel="noreferrer noopener">http://forestinfo.it</a></p>



<p>forestinfo.it is based on Lizmap, an open-source software designed by 3Liz, that allows to create Web map applications from QGIS® Desktop.</p>



<p>At the moment in forestinfo.it you can navigate in <strong>three </strong>layers.</p>
